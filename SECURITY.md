# Security policy

gibson is a demo, but the image is meant to be safe to expose. If you find a
way to crash the server, exhaust the host it runs on, or escape the container,
please report it privately through
[GitHub's private vulnerability reporting](https://github.com/SpechtLabs/gibson/security/advisories/new)
rather than in a public issue.

Only the latest release is supported. Fixes ship as a new release, and the
`latest` image tag moves to it.
